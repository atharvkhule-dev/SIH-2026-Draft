# Cooperative Gig Services Platform

A trusted, community-driven marketplace for finding and offering local services. Built with React 18, TypeScript, Vite, Tailwind CSS, and React Router.

## Features

- **Dual-Role Account**: Seamless switching between Customer ("Find Services") and Provider ("Offer Services") modes on a single account.
- **Accessibility-First UI**: Large touch targets, high contrast, plain language labels (icons + text), simple navigation.
- **Service Discovery & Natural Language Search**: Quick category browsing, smart filters, and AI query parser ("I need someone to clean my 2BHK tomorrow evening").
- **FairPrice AI**: Dynamic pricing recommendations based on service type, duration, location, experience, and local benchmarks.
- **Transparent Booking & Escrow**: Clear fee breakdown (Provider share, Platform fee, Cooperative Community Fund contribution) with held-in-escrow status.
- **QR Job Verification**: Interactive QR scanning simulation for Start Job and End Job status transitions.
- **Provider & Earnings Dashboards**: Manage active services, view earnings breakdown, pending vs available funds, payout history.
- **Admin Dashboard**: Verification request approvals, gig moderation, dispute handling, community fund statistics.
